# TrialScope: Clinical Trial Representation Analysis

## Project goal

This project investigates representation patterns in recent Type 2 diabetes clinical trials using public ClinicalTrials.gov data.

## Research question

How do trial size, participant eligibility, sex eligibility, sponsor type, location, and study status vary across Type 2 diabetes clinical trials?

## Skills being developed

- Python
- Pandas and NumPy
- SQL
- Data cleaning and quality auditing
- Reproducible research with Git and GitHub
